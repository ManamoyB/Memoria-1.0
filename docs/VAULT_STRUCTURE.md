# MemoriaOS Obsidian Vault Structure

| Folder | Purpose |
| --- | --- |
| `00-Inbox` | Material awaiting review |
| `01-Raw-Documents` | Faithful notes generated from Agent 01 |
| `02-Knowledge` | Curated knowledge notes (future Knowledge Writer) |
| `03-Topics` | Topic pages (future classification/context agents) |
| `04-Entities` | People, organizations, technologies and concepts |
| `05-Projects` | Project-specific knowledge |
| `06-Summaries` | Generated summaries (future agent; never replace raw notes) |
| `07-Relationships` | Cross-document and knowledge relationships |
| `08-System` | Templates, schemas and operational documentation |

Phase 2 creates all folders but writes Agent 01 output only to `01-Raw-Documents`. Later agents may route reviewed knowledge into other folders.
